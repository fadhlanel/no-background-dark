# No Background Dark

Resource pack Minecraft yang menghapus blur GUI, lapisan gelap, dan efek vignette.

## Fitur

- Menghapus blur latar GUI.
- Menghapus lapisan gelap pada menu.
- Menghapus efek vignette.
- Dunia tetap terlihat saat menu terbuka.
- Client-side. Tidak perlu dipasang di server.
- Tidak menambah beban performa.

## Instalasi

1. Unduh file `.zip` dari [rilis terbaru](https://github.com/fadhlanel/no-background-dark/releases/latest).
2. Pindahkan file ke `.minecraft/resourcepacks/`.
3. Buka **Options** → **Resource Packs** di Minecraft.
4. Aktifkan **No Background Dark**, lalu klik **Done**.

> Jangan ekstrak file `.zip` hasil unduhan.
